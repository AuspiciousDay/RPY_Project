# 중간 목표 — 5분 생존 게임 프로토타입

## 1. 프로젝트 목표

뱀파이어 서바이벌 스타일의 2D 생존 게임을 구현한다.

플레이어는 5분 동안 몬스터를 피하거나 자동 공격으로 처치하며, 경험치를 획득하고 무기를 강화해 생존하는 것을 목표로 한다.

## 2. 핵심 구현 기능

### 플레이어 시스템
- [ ] WASD를 이용한 8방향 이동
- [ ] 이동 방향에 따른 캐릭터 좌우 반전
- [ ] 플레이어 체력 및 피격 처리
- [ ] 체력이 0이 되면 게임 오버

### 몬스터 시스템
- [ ] 플레이어 카메라 화면 밖의 랜덤 위치에서 몬스터 생성
- [ ] 몬스터가 플레이어를 자동으로 추적
- [ ] 몬스터 체력 및 피격 처리
- [ ] 체력이 0이 되면 몬스터 사망
- [ ] 몬스터 사망 시 50% 확률로 경험치 보석 드롭

### 전투 시스템
- [ ] 플레이어 자동 공격 구현
- [ ] 기본 무기 1종 구현
- [ ] 일정 시간마다 자동으로 공격
- [ ] 공격과 몬스터의 충돌 판정
- [ ] 몬스터에게 데미지 적용

### 경험치 및 레벨업 시스템
- [ ] 경험치 보석 획득
- [ ] 보석 획득 시 경험치 증가
- [ ] 일정 경험치에 도달하면 레벨업
- [ ] 레벨업 시 무기 강화 선택지 3개 표시
- [ ] 강화 선택 시 무기 능력치 반영

#### 무기 강화 선택지

| 강화 종류 | 효과 |
|---|---|
| 공격 범위 증가 | 공격 범위 또는 투사체 크기 증가 |
| 공격 개수 증가 | 한 번에 생성되는 공격 개수 증가 |
| 공격 쿨타임 감소 | 자동 공격 간격 감소 |

### 게임 진행 시스템
- [ ] 게임 시작 시 5분 타이머 작동
- [ ] 남은 시간 UI 표시
- [ ] 5분 생존 시 게임 클리어
- [ ] 플레이어 체력 0 이하 시 게임 오버
- [ ] 승리 및 패배 화면 표시

- [ ] 선택한 강화 효과가 실제 공격에 반영된다.
- [ ] 플레이어가 사망하면 게임 오버가 발생한다.
- [ ] 5분 동안 생존하면 게임 클리어가 발생한다.
